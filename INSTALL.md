# Установка MicPilot

Это первая тестовая версия для Windows 11 x64. .NET уже включён; Python и видеокарта для обработки не нужны. Для RNNoise требуется процессор с AVX2.

1. Скачайте ZIP из [Releases](https://github.com/xChessman-dev/MicPilot/releases).
2. Распакуйте всю папку в каталог с правом записи, например `F:/Apps/MicPilot`. Не запускайте EXE внутри ZIP и не переносите его отдельно.
3. Запустите `MicPilot.exe`. Выберите физический микрофон и выход.
4. Для Discord, игр и OBS установите виртуальный кабель отдельно из официального источника [VB-Audio](https://vb-audio.com/Cable/): выход MicPilot — **CABLE Input**, микрофон целевого приложения — **CABLE Output**.
5. Проверьте оригинал и обработку на короткой записи. Не отправляйте исходный и обработанный микрофон одновременно.

В ZIP включены RNNoise и его лицензия, но нет записей и настроек пользователя. Приложение не подписано цифровым сертификатом; Windows может показать предупреждение. Не отключайте защиту Windows. Проверить целостность можно командой `Get-FileHash ./MicPilot-0.1.0-beta.1-win-x64.zip -Algorithm SHA256` и файлом `.sha256`.

Сборка и автоматические проверки не заменяют прослушивание и длительный тест на вашем ПК. Трей, автозапуск и автоматическое восстановление устройства пока не реализованы.
